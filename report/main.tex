\begin{abstract}
A single ability estimate can miss a subject's relative strengths across item types, while local adaptation from very few labels can overreact to individual outcomes. We present \textbf{ASRP (Adaptive Support-Based Response Prediction)}, which addresses this tension by shifting from public-data priors and content-based Rasch estimation at low label budgets to support-conditioned kernel residuals as evidence accumulates. A fixed budget-dependent ensemble controls this transition, shrunk topic corrections adjust systematic errors, and a streaming acquisition rule selects labels using covariance gain. Across \ProxyDraws{} public-data draws following the documented formative protocol, ASRP achieves mean Brier ALC $\ASRPAdaptiveALC{}$ versus $\EMAdaptiveALC{}$ for Empirical Mean with identical adaptively acquired labels. Paired policy comparisons separate overall prediction quality from label selection.
\end{abstract}

\section{Introduction}

The Predictive AI Evaluation Competition (PAIEC) asks for an AI system's success probability on an individual item with at most 31 revealed labels per subject--benchmark pair. It requires both zero-label prediction and adaptation from sparse responses. Our target is query-level success, following the distinction from confidence in a particular generated answer made by \citet{capability_calibration}.

\textbf{Shared structure and local evidence address different limitations.} Item response theory models subject ability and item difficulty \citep{lord1980}, while amortized evaluation predicts difficulty from content \citep{amortized_eval}. This shared structure supports cold-start prediction, but a scalar ability cannot express every relative strength across item types, and frozen estimates may transfer imperfectly to new benchmarks. Conversely, local corrections learned from one or two labels can overreact to individual outcomes. ASRP therefore combines prior-based estimation with regularized support-driven adaptation, increasing the latter's weight as evidence grows.

ASRP couples two prediction branches. A Rasch hybrid combines difficulty from frozen MiniLM representations \citep{wang2020minilm}, updated subject ability, and metadata-informed smoothing. A kernel probe learns item-dependent residuals around a smoothed subject baseline from revealed responses. \textbf{Budget-dependent mixing} controls their relative influence. Shrunk topic calibration corrects systematic public-data residuals, while covariance-based acquisition selects labels from the candidate stream. This integration is accompanied by released source selections, matched splits, predictions, and acquisition traces for reproducible evaluation.

\section{Competition Setting and Data}\label{sec:setting}

\subsection{Prediction interface and metrics}

At runtime the platform supplies a pair of dictionaries $x=(s,i)$ describing a subject and an item, together with a list of previously acquired binary observations. The predictor returns a finite probability in $[0,1]$. Eligible subject--benchmark groups have at least 80 distinct items. The platform creates a fixed acquisition/evaluation split and evaluates the same evaluation items at the \textbf{six label budgets}
\[
  n \in \{0,1,3,7,15,31\}.
\]
Acquisition items are never scored and evaluation outcomes are never revealed. The optional acquisition hook receives the current candidate, acquired labels, and remaining-label context; the interface can also supply a current prediction when requested. ASRP uses the first three inputs.

For a budget $n$ and a subject--benchmark group with $N_{\mathrm{eval}}$ evaluated responses, the Brier score is the mean squared error between the predicted probability $p$ and the binary outcome $y$:
\[
  B_n = \frac{1}{N_{\mathrm{eval}}}\sum_{j=1}^{N_{\mathrm{eval}}}(p_j-y_j)^2.
\]
The group-level Brier ALC is the normalized area on the logarithmic budget axis and is equivalent to
\[
  \alc = 0.1B_0+0.2B_1+0.2B_3+0.2B_7+0.2B_{15}+0.1B_{31}.
\]
The official score averages these group-level ALC values equally across subject--benchmark groups. \textbf{Lower is better.} All reported local tables use this same weighting.

\subsection{Public data and frozen artifacts}

The predictor uses frozen artifacts trained and calibrated from the public \path{aims-foundations/measurement-db} release \citep{measurementdb}. Public responses provide subject priors and metadata statistics, while item content supplies semantic features. The local evaluation samples from \EligibleGroups{} eligible subject--benchmark groups in \EligibleSources{} sources within a fixed inventory of 142 binary sources; Section~\ref{sec:setup} describes selection and splitting. Appendix~\ref{app:sources} lists the evaluated sources. Upstream metadata and licenses remain authoritative.

The subject prior and metadata statistics are frozen public-response aggregates. Their runtime use and fallback rules are specified in Appendix~\ref{app:implementation}; reproducing the reported scores uses the released weights without refitting them. MiniLM is used as a pretrained encoder; the packaged encoder is \path{sentence-transformers/all-MiniLM-L6-v2}, based on MiniLM \citep{wang2020minilm}. Its weights are \textbf{frozen at runtime}. The difficulty model, priors, kernel configuration, calibration statistics, and cluster centroids are prepared offline and bundled with the submission; kernel residual coefficients are fitted online from revealed labels. The current submission uses \textbf{no external LLM or web search API during scoring}. At runtime, the program uses only the supplied subject and item attributes, anonymous benchmark identifiers, and labels revealed within the allowed budget; it does not access hidden evaluation outcomes.

\subsection{Item representation and amortized difficulty}\label{sec:difficulty}

MiniLM encodes the normalized item text as $e_i\in\mathbb R^{384}$. Six deterministic numeric text features form $z_i\in\mathbb R^6$. A frozen feed-forward network standardizes their concatenation and predicts a clipped difficulty:
\[
 d_i=\operatorname{clip}\!\left(f_\phi([e_i;z_i]),-2,2\right).
\]
The network has dimensions 390--128--32--1 and ReLU hidden layers. This amortized estimate supplies a difficulty for an unseen item without fitting an item-specific parameter online. Appendix~\ref{app:features} specifies text limits, pooling, and standardization.

\subsection{Public prior and Rasch update}\label{sec:rasch}

A frozen subject offset $o_s$, looked up by normalized model name, defines a prior mean and initial ability:
\[
 \mu_s=\operatorname{clip}(0.5+0.5o_s,0.05,0.95),\qquad
 \theta_{0,s}=\operatorname{logit}(\mu_s).
\]
An unknown name has $o_s=0$. With revealed labels, clipped Newton--Raphson iterations approximate the \textbf{maximum a posteriori (MAP) estimate} under a Bernoulli Rasch likelihood and Gaussian ability prior $\mathcal N(\theta_{0,s},v_\theta)$, with $v_\theta=2$. The resulting ability $\hat\theta_s$ gives
\[
 p_{\mathrm{Rasch}}=\sigma(\hat\theta_s-d_i),\qquad
 \sigma(t)=(1+e^{-t})^{-1}.
\]
At $n=0$, $\hat\theta_s=\theta_{0,s}$. Separately, a query-specific metadata prior $p_{\mathrm{meta}}(s,i)$ combines frozen subject and visible-feature counts. The hybrid smooths observed successes toward this prior and blends the result with the Rasch probability:
\[
 p_{\mathrm{smooth}}=\frac{S_s+\kappa p_{\mathrm{meta}}(s,i)}{n+\kappa},\qquad
 p_{\mathrm{hybrid}}=(1-\eta_n)p_{\mathrm{smooth}}+\eta_n p_{\mathrm{Rasch}},\qquad \kappa=4.
\]
Here $\eta_n$ is the frozen Rasch mixing weight. Appendix~\ref{app:priors} gives the prior lookup and Newton updates; Appendix~\ref{app:ensemble} lists the six mixing weights.

\subsection{Support-conditioned kernel probe}\label{sec:kernel}

The kernel branch adds an item-dependent correction to a conservative subject baseline. It encodes visible text, metadata, and interactor descriptions into semantic vectors $\mathbf h_i$ and lexical vectors $\boldsymbol\ell_i$. A locally normalized similarity kernel $K$ is fitted using only the support features in $\mathcal D_b$; the query does not change this geometry.

For each supported subject $s$, let $n_s$ and $S_s$ be its revealed-label and success counts. A two-component Beta mixture has concentrations $(c_1,c_2)=(1,8)$, prior masses $(\pi_1,\pi_2)=(0.3,0.7)$, and posterior weights $\omega_{sk}$. Its mean is
\[
 b_s=\sum_{k=1}^{2}\omega_{sk}\frac{c_k\mu_s+S_s}{c_k+n_s}.
\]
Subject-centered kernel ridge regression, with penalty $\lambda_K=0.3$, fits residual coefficients $\gamma$ from the revealed labels. With query-to-support similarities $\mathbf k_i$ and subject mean fitted contribution $\bar f_s$, the prediction is
\[
 p_{\mathrm{kernel}}=\operatorname{clip}\!\left(b_s+\mathbf k_i^\top\gamma-\bar f_s,0,1\right).
\]
Appendix~\ref{app:kernel} defines $K$, the Beta weight update, and the centered linear solve. If the current subject has no revealed labels, this branch returns $\mu_s$. The implementation supports multiple subjects within a benchmark; the evaluator supplies evidence across all sampled groups, and this branch filters it to the current benchmark.

The ensemble gives the kernel weights $w_n=(0,0,0.2,0.4,1,1)$ at budgets $(0,1,3,7,15,31)$. Thus the Rasch hybrid supplies the cold-start prediction, while a larger support set allows the local residual to receive more weight. These are design choices encoded in the released configuration.

\subsection{Topic calibration}\label{sec:calibration}

A frozen topic correction $\Delta_n(i)$ adjusts the ensemble using the first matching topic entry in visible metadata. Without a match, the model uses the closest of eight frozen embedding centroids. Count-based shrinkage and caps limit the adjustment to $0.06$ for explicit topics or $0.03$ for clusters. Missing statistics give zero correction.

The budget-specific ensemble is followed by topic correction:
\[
 p_{\mathrm{final}}=\operatorname{clip}\!\left(
 (1-w_n)p_{\mathrm{hybrid}}+w_n p_{\mathrm{kernel}}+\Delta_n(i),0,1\right).
\]
Appendix~\ref{app:ensemble} gives the exact correction and lookup rules.

\subsection{Adaptive acquisition}\label{sec:acquisition}

The \textbf{\texttt{adaptive\_4\_warm}} hook skips up to 16 early candidates to establish feature geometry, without revealing their labels. A reference set $\mathcal P$ deduplicates the last 64 seen candidates by visible text, metadata, and interactor features. For the current candidate $*$, a conditional covariance gain $G_*$ is a feature-based uncertainty-reduction surrogate over $\mathcal P$. It depends on acquired-item features, but not on their outcome values, and does not directly estimate a change in Brier score. Normalizing and capping this gain, then raising it to power four, gives utility $V_*$.

For $L$ labels and $R$ candidates remaining, including the current candidate, the acquisition probability is
\[
 \pi_*^{\mathrm{acq}}=\min\!\left(1,\frac{L}{R}\operatorname{clip}\!\left(
 \frac{V_*}{\max(\overline V_{\mathcal P},10^{-12})},0.05,20\right)\right),\qquad
 \overline V_{\mathcal P}=\frac{1}{|\mathcal P|}\sum_{j\in\mathcal P}V_j.
\]
A deterministic uniform hash supplies the draw. When $R\le L$ and $L>0$, every remaining candidate is acquired, overriding warm-up. Appendix~\ref{app:acquisition} defines $G_j$, $V_j$, and the boundary cases. The rule uses only acquired support and already-seen/current features; it never accesses future candidates or unseen outcomes.

\section{Experimental Setup}\label{sec:setup}

We use paired public-data comparisons to separate prediction and acquisition effects, and report private-platform evaluations separately. Code, frozen artifacts, and exact reproduction commands are provided in Appendix~\ref{app:reproducibility}.

\subsection{Public formative simulation}

\paragraph{Complete groups and repeated draws.}
The pinned public snapshot contains \EligibleGroups{} eligible subject--benchmark groups in \EligibleSources{} sources, each with 80--1,000 distinct items. We predeclare \textbf{\ProxyDraws{} draw seeds}. Each draw selects complete groups under a \textbf{total 1,000-pair cap}, preferring less-represented benchmarks and subjects with random tie-breaking; groups that do not fit are skipped. The draws cover \ProxyGroups{} distinct groups from \ProxySources{} sources, with \ProxyMinGroups{}--\ProxyMaxGroups{} groups and \ProxyMinPairs{}--\ProxyMaxPairs{} pairs per draw.

\paragraph{Fixed pools and all responses.}
One snapshot seed fixes each group's 50/50 item split and candidate order across draws. All runs of an item stay together. Acquisition reveals one fixed recorded response per selected item; \textbf{all recorded evaluation responses are scored}, reusing a prediction for identical visible inputs. Across draws, this yields \ProxyTargets{} evaluation-item occurrences and \ProxyResponses{} response occurrences per policy, including repeated appearances of groups.

\paragraph{Matched evidence and checkpoint barriers.}
ASRP and Empirical Mean use the same draws and pools under Random and Adaptive acquisition. Predictors share labels within each policy; policies may select different labels. One trajectory supplies nested prefixes. \textbf{Every group completes a checkpoint before evaluation}; each call receives all evidence revealed across groups, excluding future labels and evaluation outcomes. Ablations use these same labels and frozen artifacts.

\paragraph{Alignment.}
These constraints follow the public rules and starting kit. Private coordinator details are unavailable, so benchmark-first tie-breaking, group scheduling, and acquisition-response selection remain explicit local choices (Appendix~\ref{app:protocol}). This is a \textbf{public simulation of the documented design}, not an exact private-sampler replay or a source-held-out test; public fitting and calibration overlap the evaluation release.

\subsection{Baseline and score aggregation}

We use the \textbf{Empirical Mean predictor} from the official PAIEC repository \citep{paiec_baselines}:
\[
 p_{\mathrm{EM}}=
 \begin{cases}
  0.5, & n=0,\\
  \frac{1}{n}\sum_{k=1}^{n}y_k, & n>0.
 \end{cases}
\]
It uses only the current subject--benchmark group's acquired labels, without item features or a learned prior. Random is its default acquisition policy; the Adaptive variant uses ASRP's selected labels.

We use the metrics in Section~\ref{sec:setting}: average all response losses within a group, groups equally within a draw, then the \ProxyDraws{} draws equally. We report sample SD and range across draw scores. Paired differences compare methods on the same draw. Repeated appearances of a group are retained as part of the sampling distribution; draw SD describes composition variability, not independent evidence about new-source transfer.

\subsection{Official formative feedback}

We separately evaluate the same with-Rasch ASRP + \texttt{adaptive\_4\_warm} ZIP in \OfficialRuns{} Codabench formative runs. Each run samples a private subset. We average group scores equally within each run, then report the mean and sample SD across runs using all six budgets. Appendix~\ref{app:official} records the submission IDs and available feedback.

\section{Mathematical and Implementation Details}\label{app:implementation}

These equations specify inference with the released frozen artifacts at the six competition budgets. They use the same symbols as Section~\ref{sec:method}. The reproduction command evaluates these artifacts without repeating their original offline fitting. Throughout, $\operatorname{clip}(x,l,u)=\min(u,\max(l,x))$, applied coordinatewise to vectors, and $\operatorname{norm}(x)=x/\max(\|x\|_2,10^{-12})$.

\paragraph{Shared notation.}
A support row $r$ contains a subject $s_r$, item $i_r$, and binary outcome $y_r$. The row collection $\mathcal D_b$ contains all revealed responses for benchmark $b$ and has size $M$. Its subject-specific subset $\mathcal D_s$ has $n_s$ rows and $S_s$ successes. For the current query subject, the budget is $n=n_s\le31$. The kernel can share residual evidence across subjects in the same benchmark; $M$ need not equal $n$. Runtime subject identity uses the complete subject dictionary, whereas frozen subject-prior lookup uses \texttt{normalized\_name}.

We distinguish $\eta_n$ (Rasch mixing weight), $w_n$ (kernel mixing weight), and $\lambda_K$ (ridge penalty). Beta component index $k\in\{1,2\}$ has concentration $c_k$, prior mass $\pi_k$, and posterior mass $\omega_{sk}$. Acquisition uses gain $G_j$, utility $V_j$, probability $\pi_*^{\mathrm{acq}}$, and uniform variate $\xi$; none denotes an embedding coordinate.

\subsection{Feature construction for Section~\ref{sec:difficulty}}\label{app:features}

The Rasch encoder normalizes whitespace, takes the first 6,000 characters of item content, and tokenizes to at most 256 tokens. Masked mean pooling followed by $L_2$ normalization gives $e_i\in\mathbb R^{384}$. The six coordinates of $z_i$ are $\log(1+\text{text length})/10$, digit fraction, non-ASCII fraction, and indicators for code, mathematical notation, and a question mark. Fractions and the question-mark indicator use the first 2,000 characters; code/math markers use the first 6,000. Text length is measured before these truncations.

For stored feature mean $\bar{\mathbf x}$ and scale $\boldsymbol\sigma_x$, the difficulty network receives $\operatorname{clip}(([e_i;z_i]-\bar{\mathbf x})\oslash\boldsymbol\sigma_x,-10,10)$, where $\oslash$ denotes coordinatewise division. Frozen weights in \path{difficulty_model.npz} implement the 390--128--32--1 map; the final scalar is clipped to $[-2,2]$ by \texttt{\_predict\_hybrid}, after \texttt{\_difficulty} evaluates the network.

The kernel encoder uses a separate text construction containing item content, metadata, and interactor descriptions. It pools up to four evenly spaced windows of 254 content tokens, each with special tokens, normalizes each pooled vector, and normalizes their sum to obtain $\mathbf h_i\in\mathbb R^{384}$. The lexical vector $\boldsymbol\ell_i\in\mathbb R^{8192}$ uses signed CRC32 hashing of lowercased tokens and adjacent token bigrams, weights $1+\log(\text{count})$, and $L_2$ normalization. Only these semantic and lexical coordinates enter the kernel. See \path{ml_features.py}, \path{window_features.py}, and \path{evidence_features.py} under \path{src/asrp/}.

\subsection{Priors and ability update for Section~\ref{sec:rasch}}\label{app:priors}

\paragraph{Two distinct frozen priors.}
The scalar $o_s$ comes from \path{binary_subject_prior.json}. It defines $\mu_s$ and $\theta_{0,s}$ exactly as in Section~\ref{sec:rasch}. The metadata prior $p_{\mathrm{meta}}(s,i)$ instead uses the success/count tables in \path{feature_prior.json}; it corresponds to \texttt{\_feature\_prior} and the runtime variable \texttt{p\_source} in \path{src/asrp/model.py}. The released source-prior weight is one, prior shift is zero, and metadata-match adaptation weight is zero.

Let $(A_0,N_0)$ be global public successes and counts, and $(A_s,N_s)$ the subject totals. The frozen rates are
\[
 q_0=\frac{A_0}{\max(N_0,1)},\qquad q_s=\frac{A_s+8q_0}{N_s+8}.
\]
Unknown subjects use global totals. Their offset $o_s$ is separately zero, so $\theta_{0,s}=0$, but $p_{\mathrm{meta}}(s,i)$ need not equal $0.5$. All released global totals have positive counts.

For each token $t$ in the query metadata with stored global counts, let $q_t=A_t/\max(N_t,1)$. When subject--token counts exist,
\[
 q_{st}=\frac{A_{st}+8q_t}{N_{st}+8},\qquad
 \rho_{st}=\frac{\min(N_{st},80)}{\min(N_{st},80)+12}.
\]
Otherwise $q_{st}=q_t$ and $\rho_{st}=\min(N_t,300)/[\min(N_t,300)+100]$. For the set $\mathcal T(i)$ of matching tokens,
\[
 p_{\mathrm{meta}}(s,i)=\operatorname{clip}\!\left(
 \frac{2q_s+\sum_{t\in\mathcal T(i)}\rho_{st}q_{st}}
      {2+\sum_{t\in\mathcal T(i)}\rho_{st}},0.03,0.97\right).
\]
An empty token set gives clipped $q_s$. Token parsing, deduplication, and stop words follow \texttt{\_feature\_tokens}. The packaged artifact is present; if it were absent, the runtime fallback would be $\mu_s$.

\paragraph{MAP objective and numerical update.}
Using only $\mathcal D_s$, the penalized Bernoulli log-likelihood is
\[
 \mathcal L_s(\theta)=\sum_{r\in\mathcal D_s}
 \left[y_r\log\sigma(\theta-d_{i_r})+(1-y_r)\log(1-\sigma(\theta-d_{i_r}))\right]
 -\frac{(\theta-\theta_{0,s})^2}{2v_\theta},\qquad v_\theta=2.
\]
Starting at $\theta_{0,s}$, \texttt{update\_ability} computes
\[
 \begin{aligned}
 p_r(\theta)&=\sigma(\operatorname{clip}(\theta-d_{i_r},-40,40)),\\
 J_s(\theta)&=\sum_{r\in\mathcal D_s}(y_r-p_r(\theta))-(\theta-\theta_{0,s})/v_\theta,\\
 \mathcal I_s(\theta)&=\sum_{r\in\mathcal D_s}p_r(\theta)(1-p_r(\theta))+1/v_\theta,\\
 \delta_\theta&=\operatorname{clip}\!\left(J_s(\theta)/\max(\mathcal I_s(\theta),10^{-6}),-2,2\right),\qquad
 \theta\leftarrow\theta+\delta_\theta.
 \end{aligned}
\]
Here $J_s$ is the gradient and $\mathcal I_s$ the positive negative-Hessian magnitude, not the Hessian itself. The routine stops after 30 iterations or when $|\delta_\theta|<10^{-7}$, then clips $\hat\theta_s$ to $[-12,12]$. With no labels it returns $\theta_{0,s}$ directly. The runtime sigmoid also clips its logit to $[-40,40]$ when computing $p_{\mathrm{Rasch}}$. The hybrid uses at most the first 31 matching labels in acquisition order.

\subsection{Kernel calculations for Section~\ref{sec:kernel}}\label{app:kernel}

\paragraph{Support-only geometry and bandwidth.}
For $M>1$ rows in $\mathcal D_b$, let $\bar{\mathbf h}$ and $v_j^{\mathrm{feat}}$ be the coordinatewise semantic mean and population variance (divisor $M$). Define semantic scales $t_j$ and lexical weights $\nu_\ell$ by
\[
 t_j=\left[v_j^{\mathrm{feat}}+\max(\operatorname{median}_j v_j^{\mathrm{feat}},10^{-7})\right]^{-1/2},\qquad
 \nu_\ell=\log\frac{1+M}{1+f_\ell}+0.1,
\]
where $f_\ell=\sum_{r\in\mathcal D_b}\mathbf1[|\ell_{i_r,\ell}|>10^{-10}]$. Both support and query use
\[
 \widetilde{\mathbf h}_i=\operatorname{norm}((\mathbf h_i-\bar{\mathbf h})\odot\mathbf t),\qquad
 \widetilde{\boldsymbol\ell}_i=\operatorname{norm}(\boldsymbol\ell_i\odot\boldsymbol\nu).
\]
For $M=1$, the mean is zero and both weight vectors are all ones. No query feature enters these fitted statistics.

For support rows $r,t$, define
\[
 Q_{rt}=\tfrac12\left(\widetilde{\mathbf h}_{i_r}^{\top}\widetilde{\mathbf h}_{i_t}
 +\widetilde{\boldsymbol\ell}_{i_r}^{\top}\widetilde{\boldsymbol\ell}_{i_t}\right),\qquad
 K_{rt}=\exp\!\left(\frac{\min(Q_{rt}-1,0)}{h_K}\right).
\]
Take distances $\max(1-Q_{rt},0)$ over unordered off-diagonal pairs, retain those above $10^{-8}$, and let $d_{\mathrm{med}}$ be their median (or $0.1$ if none remain). The bandwidth is $h_K=4\max(d_{\mathrm{med}},10^{-5})$. The vector $\mathbf k_i\in\mathbb R^M$ uses this same transformation and bandwidth between query $i$ and each support row. These operations correspond to \texttt{fit\_geometry}, \texttt{fit\_evidence}, and \texttt{predict\_fitted} in \path{src/asrp/project_core.py}.

\paragraph{Beta mixture.}
For component $k\in\{1,2\}$, let $\alpha_{sk}=\mu_sc_k$ and $\beta_{sk}=(1-\mu_s)c_k$, with $(c_1,c_2)=(1,8)$. The normalized posterior masses are
\[
 \widetilde\omega_{sk}=\pi_k
 \frac{\mathrm B(\alpha_{sk}+S_s,\beta_{sk}+n_s-S_s)}{\mathrm B(\alpha_{sk},\beta_{sk})},\qquad
 \omega_{sk}=\frac{\widetilde\omega_{sk}}{\sum_{k'=1}^{2}\widetilde\omega_{sk'}},\qquad
 (\pi_1,\pi_2)=(0.3,0.7).
\]
Here $\mathrm B$ is the beta function. The implementation evaluates log-beta functions and normalizes by log-sum-exp. These weights give $b_s$ in Section~\ref{sec:kernel}. If the current subject is absent from the support, \path{kernel_probe.py} returns $\mu_s$ without fitting a residual for that subject.

\paragraph{Centered ridge fit.}
Let $Z\in\{0,1\}^{M\times J}$ be the membership matrix for the $J$ subjects present in the support, and $D=\operatorname{diag}(n_1,\ldots,n_J)$. Every diagonal count is positive. Let $I_M$ be the $M\times M$ identity and $\mathbf y=(y_r)_{r\in\mathcal D_b}\in\mathbb R^M$. Define
\[
 H=I_M-ZD^{-1}Z^\top,\qquad K_c=HKH.
\]
\[
 \gamma=H\left[\tfrac12(K_c+K_c^\top)+\lambda_K I_M\right]^{-1}H\mathbf y,
 \qquad\lambda_K=0.3.
\]
The target $H\mathbf y$ subtracts each subject's empirical mean; the Beta mean $b_s$ enters the final prediction separately. The code evaluates the inverse expression with a linear solve. Symmetrization matches the floating-point implementation; in exact arithmetic $K_c$ is symmetric. The fitted subject contribution is
\[
 \bar f_s=\frac{1}{n_s}\sum_{r\in\mathcal D_s}(K\gamma)_r.
\]
Substituting $b_s$, $\gamma$, $\mathbf k_i$, and $\bar f_s$ into Section~\ref{sec:kernel} gives the implemented kernel prediction. At $n_s=0$ this residual expression is bypassed; at $n=0,1$ the final ensemble weight $w_n$ is zero.

\subsection{Mixing and calibration for Section~\ref{sec:calibration}}\label{app:ensemble}

The six released mixing weights are
\[
\begin{array}{c|rrrrrr}
 n &0&1&3&7&15&31\\\hline
 \eta_n&0.2875&0.3000&0.2875&0.2750&0.2250&0.2375\\
 w_n&0&0&0.2&0.4&1&1
\end{array}
\]
Here $\eta_n$ maps to \texttt{runtime\_config.json:lambdas}; $w_n$ is the active \texttt{PROBE\_WEIGHTS} in \path{src/asrp/model.py}; and $\lambda_K$ maps to \texttt{probe\_config.json:ridge}. They are distinct parameters. The formulas in this report concern the official checkpoint counts; defensive interpolation/fallback behavior at other counts is not used in the experiment.

Let $t=t(i)$ be the first explicit topic key--value entry, in visible metadata order, present in the frozen topic table. If none matches, assign the Rasch embedding $e_i$ to the closest of eight frozen centroids by cosine similarity and use its cluster entry. Write $C_t^{\mathrm{cal}}$ for that entry's frozen count and $r_{t,n}$ for its signed correction at budget $n$. Then
\[
 \Delta_n(i)=\operatorname{clip}\!\left(
 \frac{C_t^{\mathrm{cal}}}{C_t^{\mathrm{cal}}+a_t^{\mathrm{cal}}}\,r_{t,n},
 -d_t^{\mathrm{cal}},d_t^{\mathrm{cal}}\right),\qquad
 (a_t^{\mathrm{cal}},d_t^{\mathrm{cal}})=
 \begin{cases}(40,0.06),&\text{explicit topic},\\(200,0.03),&\text{cluster}.
 \end{cases}
\]
If no entry exists, $\Delta_n(i)=0$. Cluster cosine normalization floors norms at $10^{-8}$ and resolves ties by the first maximum. At the six checkpoints, the residual array index is the corresponding budget index.

The correction $\Delta_n(i)$ is added after mixing the hybrid and kernel predictions with weight $w_n$. A final clip to $[0,1]$ completes \texttt{predict}.

\subsection{Covariance calculation for Section~\ref{sec:acquisition}}\label{app:acquisition}

The acquisition kernel is denoted $K^{\mathrm{acq}}$ to distinguish it from the prediction kernel $K$. Its geometry is fitted to the concatenation of acquired support $\mathcal D_b$, the reference list $\mathcal P$, and the current candidate $*$. The same visible item may appear in both support and reference positions; these occurrences remain in the concatenation. Only $\mathcal P$ itself is deduplicated. Thus acquisition may use seen but unlabeled features, whereas prediction geometry uses only acquired support features.

Use the feature normalization and RBF rule in Appendix~\ref{app:kernel}, but compute the median-distance bandwidth from pairs in $\mathcal P$ only. Let $\mathcal U$ concatenate $\mathcal P$ and $*$. For the current subject $s$, augment the kernel blocks as
\[
 \begin{aligned}
 A_{\mathcal D\mathcal D}[r,t]&=K^{\mathrm{acq}}_{\mathcal D\mathcal D}[r,t]+0.25\,\mathbf1[s_r=s_t],\\
 A_{\mathcal U\mathcal D}[j,r]&=K^{\mathrm{acq}}_{\mathcal U\mathcal D}[j,r]+0.25\,\mathbf1[s_r=s],\\
 A_{\mathcal U\mathcal U}&=K^{\mathrm{acq}}_{\mathcal U\mathcal U}+0.25\mathbf1\mathbf1^\top,
 \end{aligned}
\]
where block subscript $\mathcal D$ abbreviates $\mathcal D_b$. Conditional covariance and gain are
\[
 \Sigma=A_{\mathcal U\mathcal U}-A_{\mathcal U\mathcal D}
 (A_{\mathcal D\mathcal D}+I_M)^{-1}A_{\mathcal U\mathcal D}^\top,\qquad
 G_j=\max\!\left(
 \frac{|\mathcal P|^{-1}\sum_{r\in\mathcal P}\Sigma_{rj}^{2}}
      {1+\max(\Sigma_{jj},0)},10^{-12}\right).
\]
The identity term implements unit observation noise; without support, the subtraction is omitted. Define
\[
 \overline G_{\mathcal P}=|\mathcal P|^{-1}\sum_{r\in\mathcal P}G_r,\qquad
 V_j=\left[\min\!\left(\frac{G_j}{\max(\overline G_{\mathcal P},10^{-12})},20\right)\right]^4.
\]
These utilities enter $\pi_*^{\mathrm{acq}}$ in Section~\ref{sec:acquisition}. The power four is applied before dividing by mean reference utility. Gain depends on support membership and features; the numerical values of the revealed outcomes do not enter this covariance calculation.

\paragraph{Acquisition rules and reproducibility.}
Let $A$ be the initial candidate count and $B_{\max}=31$ the total label allowance in this experiment. Warm-up skips the first $W=\min(16,\max(0,A-B_{\max}))$ candidates. Checks occur in this order: reject if $L\le0$; acquire if $R\le L$; otherwise skip during warm-up. After warm-up, an empty reference list falls back to probability $L/R$; otherwise use $\pi_*^{\mathrm{acq}}$.

To ensure reproducibility, we generate a deterministic pseudorandom value $\xi\in[0,1)$ from the current context and input using SHA256. We acquire the label when $\xi<\pi_*^{\mathrm{acq}}$, using $L/R$ as the fallback acquisition probability. The reference list uses the last 64 candidates before the current one, deduplicated by the hash of visible item text/metadata/interactor content. Skipped outcomes are never supplied. See \texttt{AdaptiveGainPolicy.choose} in \path{src/asrp/adaptive_gain_policy.py}.

\section{Formative Simulation Details}\label{app:protocol}

The local sampler is implemented in \path{tools/draw_protocol.py}. For each draw it filters to unselected complete groups that fit the remaining 1,000-pair allowance. It selects a benchmark with minimum representation in the current draw, then a feasible subject with minimum draw-wide representation among that benchmark's candidates; seeded hash ranks break ties at each stage. Counts reset between draws. The snapshot seed separately fixes the item partition, candidate order, and recorded response revealed for an acquired item. Stable aliases derive from public identities, and are not the private platform's identifiers.

Within each checkpoint, groups advance sequentially in draw order. Later groups can use evidence already revealed by earlier groups, but no group receives evidence from a higher checkpoint. All groups finish the cap before predictions are committed. The model and acquisition policy filter global evidence using the visible subject dictionary and anonymous benchmark ID. Repeated response rows are preserved, and prediction reuse never changes their scoring weight. Missing metadata can make different upstream subjects indistinguishable through the visible interface; no identifying fields are invented.

The public starting-kit documentation specifies the complete-group draw preference but does not expose the coordinator implementation. The local hierarchy, RNG, group scheduling, alias assignment, and acquisition-response selection therefore remain explicit implementation choices. The protocol audit and source checksums are released in \path{experiments/formative_protocol.md}. These choices provide a reproducible approximation to the published design; they cannot reproduce private group selection or remove overlap with public offline fitting.
