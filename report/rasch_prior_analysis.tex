\paragraph{Complementarity with the public count prior.} With the count prior removed, retaining Rasch lowers $B_0$ from $0.24409$ to $0.24192$ and $B_1$ from $0.22738$ to $0.22675$ (Table~\ref{tab:rasch_prior}). With the count prior available, the zero-label benefit is smaller and the one-label effect is adverse. \textbf{Rasch supplies complementary low-budget information when the count-based signal is absent}; its marginal contribution depends on the retained priors and calibration. Pre-calibration comparisons in Appendix~\ref{app:prior_ablation} show that topic correction affects the size and sign of these gains. This supports retaining Rasch as part of the calibrated hybrid, without asserting that the fallback condition represents private competition data.
